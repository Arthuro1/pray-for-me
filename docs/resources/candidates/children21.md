**Tagging rule followed:** every entry carries `children`, `parenting` or
`family-discipleship` (the plan's test requires this, because the shared
`relationships` domain is mostly couples/dating material). No adult-couple
topic (`marriage`, `singleness`, `dating`, `friendship`, `identity`,
`character`, `family`, `church`, `prayer`) is used. The narrow extras are the
ones the days use: `intercession`, `gospel`, `wisdom`, plus the two sensitive
tags `abuse-safety` / `sexuality`, each only on an entry that also carries a
children tag.

**Reach warning for curators:** the resolver matches on *any* shared topic, so
an entry tagged `children` or `parenting` reaches most days, not just the one
its narrow tag was meant for. `reju-on-guard` (abuse) reaches every `children`
day, and `jones-how-and-when-tell-kids-about-sex` reaches every `parenting` day,
not only days 13 and 14. The already-approved `lehmann-sexualerziehung-familiensache`
behaves the same way. A curator decides whether that is acceptable.
