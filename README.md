## ✨ Features

### 🗂️ Prayer Management
- Add personal prayer requests with title, description, and categories
- Pray **for others** — attach a person's name and phone number
- Mark prayers as **answered** and record your testimony
- Resume answered prayers back to active if needed

### 🤖 AI-Powered Features
- **Prayer points** — Claude AI suggests prayer angles with Bible verses per point
- **Daily Bible verse** — one shared verse per day per language, generated by a server-side Edge Function
- **Scripture search** — find relevant Bible passages for any prayer topic
- Each verse shown with full text and a direct link to Bible.com
- User can add prayer points **manually** or genarate suggestion from AI
- All AI suggestions are generated in the user's language
- Attach additional Bible verses to any prayer point at any time
### 📋 Prayer Detail Page
- Full-page view for each prayer with all its updates, prayer points, and testimony
- Smooth navigation with a back arrow — no page reload

### 📅 Weekly Prayer Plan
- Create categories (Family, Health, Church, Work…) with custom emoji and color
- Assign each category to specific days of the week
- Today's tab shows only what's planned for today

### 🌍 16 Languages
Full UI support for:
**French, English, German, Portuguese, Chinese, Spanish, Hindi, Japanese, Swahili, Amharic, Indonesian, Tagalog, Korean, Russian, Arabic, Persian**

Every label, tooltip, button, and daily verse adapts to the selected language. Dynamic prayer content is translated via Claude AI and cached in Supabase.

### 📱 Progressive Web App (PWA)
- Installable on Android, iOS, and desktop
- Offline support via service worker
- App icons and splash screen configured

### 🌙 Light & Dark Mode
- Toggle between light and dark themes
- Preference saved to `localStorage` and applied instantly

### 🔔 Smart Notifications
- Daily prayer reminder at a chosen time
- Prayer follow-up prompts (every 3 days → monthly)
- Call reminder for people you pray for
- All via native browser Web Notifications API

### 🔒 Private & Secure
- Auth via Google OAuth or Email/Password (Supabase Auth)
- All data stored in your own Supabase database with Row Level Security

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/Arthuro1/pray-for-me.git
cd pray-for-me

# Install dependencies
npm install

# Copy and fill in environment variables
cp .env.example .env

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## ⚙️ Environment Variables

Create a `.env` file at the project root:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_ANTHROPIC_API_KEY=your-claude-api-key   # optional — AI features only
```

> **Note:** The Anthropic key is only used in development. In production, AI calls are routed through a Vercel serverless function to keep the key secret.

---

## 🗄️ Database Setup

Run [`supabase_schema.sql`](./supabase_schema.sql) in your Supabase SQL editor to create all tables and RLS policies.

Also create the `daily_verse` table for the shared AI-generated verse of the day:

```sql
create table daily_verse (
  date date not null,
  lang text not null,
  text text not null,
  ref text not null,
  primary key (date, lang)
);

alter table daily_verse enable row level security;
create policy "Public read" on daily_verse for select using (true);
```

---

## ☁️ Edge Functions

The `supabase/functions/generate-daily-verse` function generates one Bible verse per language per day and stores it in the `daily_verse` table. It is triggered by a daily cron job at midnight UTC.

Deploy it with:
```bash
npx supabase functions deploy generate-daily-verse
npx supabase secrets set ANTHROPIC_API_KEY=your_key_here
```

```
└── functions/
    └── generate-daily-verse/   # Edge Function: daily Bible verse cron
```

## 🌐 Deployment

The app is deployed at **[pray4me.space](https://pray4me.space)** on Vercel.

```bash
npm run build   # outputs to dist/
```

Set the same environment variables in your Vercel project settings. The `api/` folder contains a serverless function that proxies Anthropic API calls securely in production.
