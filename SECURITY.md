# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately to
[arthur.meteng@gmail.com](mailto:arthur.meteng@gmail.com) with “Praystead security”
in the subject. Do not open a public issue for a suspected vulnerability.

Include the affected version/URL, impact, minimal reproduction, and any suggested
mitigation. Do not access other users' data, run denial-of-service tests, send
real sensitive prayer content, or retain data beyond what is needed to report.
We will acknowledge receipt as soon as practical, coordinate validation and a
fix, and credit reporters who want recognition.

Supported security fixes target the current production release and `main`.
Older deployments should upgrade. Encryption guarantees and limitations are in
[`docs/ENCRYPTION.md`](./docs/ENCRYPTION.md); operational response is in
[`docs/OPERATIONS.md`](./docs/OPERATIONS.md).
